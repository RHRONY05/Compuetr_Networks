# CSE-311 Computer Networks Syllabus

Source: syllabus image provided by the student on 2026-09-05.

## Course Identity

- Course: CSE-311 Computer Networks
- Lectures: 3 hours/cycle
- Credits: 3

## Module 1: Introduction

- Definition of internet
- Network access and physical media
- ISPs and internet backbones
- Client-server and peer-to-peer network models
- Packet-switched and circuit-switched networks
- Protocol hierarchies and service models

## Module 2: Physical and Data Link Layer

- Physical and data link layer services
- Error detection and correction techniques
- Flow control
- Multiple access protocols
- CSMA
- CSMA/CD
- ALOHA and Slotted ALOHA
- Network topology
- Token Ring and FDDI
- Hub
- Bridge and switch
- STP
- LAN protocols and IEEE 802.*
- PPP
- HDLC
- ARP and RARP
- Ethernet, Fast Ethernet, Gigabit Ethernet
- ATM and Frame Relay
- Wi-Fi and WLAN architecture
- Bluetooth
- MPLS
- Virtualization

## Module 3: Network Layer

- Network layer services
- Internet Protocol
- IPv4
- IPv6
- IP addressing
- Subnetting
- VLSM
- ICMP
- DHCP and NAT
- Routing principles
- Distance vector routing
- Link state routing
- Hierarchical routing
- Multicast routing
- Router architecture
- Fragmentation and reassembly
- Congestion control
- Mobile IP
- Internetworking
- WAN technologies and protocols
- Introduction to 5G and next generation networks

## Module 4: Transport Layer

- Transport layer services
- Multiplexing and demultiplexing
- Connectionless and connection-oriented transport
- UDP
- Principles of reliable data transfer
- TCP
- Connection management
- Timer management
- Principles of congestion control
- Congestion and flow controls with TCP

## Module 5: Application Layer

- Principles of application layer protocols
- Web and HTTP
- File Transfer Protocol
- Electronic mail
- SMTP
- POP3
- IMAP
- DNS
- SNMP
- Socket programming with TCP and UDP

## Module 6: Security in Computer Networks

- Security issues in computer networks
- Principles of cryptography
- Symmetric key cryptography
- Public key encryption
- DES
- RSA
- IDEA
- MD5
- SSH
- Message integrity and digital signatures
- End-point authentication
- Diffie-Hellman key exchange algorithm
- Access-control list
- Gateway
- Firewalls
- Intrusion detection systems
- Blockchain
